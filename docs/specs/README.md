## 設計原則（不可違反）

1. 每個數值都必須在回合內產生後果，不允許只影響結局的數值。
2. 確定性隨機：同一存檔、同一回合、同一行動，結果必須完全相同（反 SL 機制）。
3. 皇帝只做皇帝該做的事：重複操作必須可委派，委派要付出權力代價。
4. 王朝大於皇帝：駕崩是換代，不是遊戲結束（Phase 4 實作，Phase 0 先保留欄位）。
