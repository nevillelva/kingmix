# 官職需求與影響

官職需求取自帝成 2 的官職配對邏輯，數值門檻為暫定，Phase 1 校準。

| 官職 | 必要條件（高） | 避免條件 | 機械影響 |
|---|---|---|---|
| 丞相 | 忠誠、智慧、政治 | 野心高 | 每年風調雨順加成；忠誠不足則有篡位風險 |
| 吏部尚書 | 智慧、政治、道德 | — | 科舉名臣率 |
| 戶部尚書 | 智慧、政治、道德 | — | 稅收與地方建設加成 |
| 工部尚書 | 智慧 | — | 戰備產量、工匠招募數 |
| 兵部尚書 | 智慧 | — | 招兵數量 |
| 知府 | 智慧、政治、道德 | 野心高、道德低 | 地方建設與稅收；道德低則貪污 |
| 總兵 | 武力、道德 | 野心高 | 城市被攻擊時的抵抗力 |
| 貿易官員 | 智慧 | 武力過低（易死於外國） | 貿易收入 |
| 帶兵大將 | 武力、智慧、統御 | — | 武力影響殺傷；智慧影響計謀；統御增加帶兵數 |
| 太傅 | 智慧、武力、道德 | 野心高 | 教導皇子能力 |

## 規則

- 任一官職的需求屬性不足時，系統顯示警示但不阻擋任命（保留玩家選擇權）。
- 「一鍵最適任」建議只列出候選人，不自動任命（去微操，但保留決策）。
- 官職空缺會每回合扣除對應效率，避免玩家永遠不任命。
