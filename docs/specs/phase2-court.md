# Phase 2 — 人事與權謀

本文件記錄 Phase 2 的實作決策。數值皆為暫定，待無頭模擬校準。

## 官員與派系

- 官員具五項能力（智慧、政治、武力、統御、道德）、忠誠、野心、派系、所任官職。
- 三大派系：`qingliu`（清流）、`xunggui`（勳貴）、`hanmen`（寒門）。**名稱為暫定**，後續可改，不影響機制。
- 派系勢力為 0–100 的分數（非占比），中性值 33。勢力高於中性，所屬官員忠誠微升；低於中性則微降。
- 科舉招募（E009）的新進士，能力基準隨文學上升。上限 12 人。

## 官職

- 需求取自 `offices.md`。不達標仍可任命，但記錄 `unfit_office` 警告。
- 同一官職只能一人，任命新人會使舊任卸任。
- **已實作效果**：戶部（每月稅收 +政治/40）、工部（每月軍備 +智慧/200）。
- **空缺懲罰**：戶部空缺每月國庫 −3。
- **延後**：丞相、兵部、知府的機械效果，留待後續階段。

## 東廠

流程：調查 → 得到把柄 → 處置。

1. 開案後，隔一個月結算。成功機率 = 0.5 + 權術/1000。
2. 成功後把柄等級 1–3。若失敗，案件以 `no_evidence` 結案。
3. 把柄出現時，該月奏摺改為「東廠密報」，三選一：
   - **銷毀警告**：野心 −10、忠誠 +10，國庫依把柄等級增加。
   - **當場問罪**：移除該官員，威儀 +5，國庫依把柄等級與其道德增加。
   - **天牢**：忠誠 −20，次月有 50% 機率逼出供詞（把柄等級 +1，最多 5 級），否則結案。
4. 移除官員時，其未結案件一併以 `removed` 結案。
