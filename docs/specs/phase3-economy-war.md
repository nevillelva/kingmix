# Phase 3 — 國策、外交與戰爭

## 國策（src/policy.js）

開局選定一種施政流派，每月提供固定修正：

| 流派 | 每月效果 | 戰力修正 |
|---|---|---|
| 重農 `agrarian`（預設） | 農業 +0.5、民心 +0.1 | ×1.0 |
| 重商 `commerce` | 商業 +0.8、國庫 +5、民心 −0.1 | ×1.0 |
| 黷武 `militarist` | 軍備 +1、民心 −0.2 | ×1.1 |
| 儒術 `confucian` | 仁德 +0.5、天命 +0.05 | ×0.9 |

## 戰爭（src/war.js）

決策制，無操作。己方戰力 = 軍備/4 + 武略×1.5 + 兵部/大將武力×2.5，乘上 0.8–1.2 的隨機浮動與國策修正。
戰力 ≥ 敵方強度為勝。勝利套用 `reward`；敗北套用 `loss` 並額外威儀 −3。所有戰果記錄於 `state.wars`。
