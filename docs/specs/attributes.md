# 屬性定義與即時影響

## 皇帝屬性

| 屬性 | 範圍 | 即時後果 | 來源參考 |
|---|---|---|---|
| 健康 | 0–100 | 低於 50 每回合壽命折損；低於 10 重病，跳過一回合 | 帝成 1、帝成 2 |
| 精力上限 | 2–3 | 每回合可用時段數（晨/午/夜） | 改自體力，見 README 設計 |
| 文學 | 0–500 | 科舉名臣率 | 帝成 2 |
| 武略 | 0–500 | 親征加成、刺殺存活率 | 帝成 1 武術 |
| 權術 | 0–500 | 東廠調查成功率、派系制衡效果 | 新增（帝成 2 東廠能力的抽象化） |
| 仁德 | 0–500 | 民心自然增長、諫官好感、天災損失 | 帝成 1 道德（改為即時） |
| 威儀 | 0–500 | 丞相造反門檻、改立太子、臣子抗旨率 | 帝成 2 皇威概念合併 |
| 聲色 | 0–500 | 過高觸發荒淫事件與外戚坐大；低於 50 後宮效率下降 | 帝成 1 魅力/快樂合併 |

## 國家屬性

| 屬性 | 範圍 | 即時後果 |
|---|---|---|
| 國庫 | ≥ 0 | 低於 0 觸發財政危機事件 |
| 民心 | 0–100 | 低於 30 起義機率上升；高於 70 稅率可提高 |
| 農業 / 商業 | 0–1000 | 稅收與人口成長基礎 |
| 軍備 | 0–1000 | 戰爭決策的兵力上限 |
| 天命 | 0–100 | 結局評分基準，每回合依仁德與民心微幅變動 |

## 官員屬性

| 屬性 | 範圍 | 用途 |
|---|---|---|
| 智慧 / 政治 / 武力 / 統御 / 道德 | 0–100 | 見 offices.md 的職位需求 |
| 忠誠 | 0–100 | 低於 60 有叛變風險 |
| 野心 | 0–100 | 高於 60 有奪權風險；忠誠 − 野心 < 20 為危險區 |

## 備註

- 上限數值（500、1000）為暫定，Phase 1 以無頭模擬校準。
- 「精力」取代帝成 1、2 的體力作為每回合行動配額；體力不再是即時管理資源。
