# Phase 8 朝堂視覺提案

本目錄為朝堂畫面的三套視覺方向示意（純靜態 HTML，無遊戲邏輯，未接入 `web/index.html`）。

| 檔案 | 方向 | 截圖 |
|---|---|---|
| `proposal-a-gongbi.html` | 工筆宮廷：絹黃底、摺本卡片、可滑動卡堆 | `proposal-a-gongbi.png` |
| `proposal-b-palace-map.html` | 宮城平面圖為主畫面，頂欄僅四項指標 | `proposal-b-palace-map.png` |
| `proposal-c-scroll.html` | 史冊卷軸：年終考評逐步展開，附數據綵帶 | `proposal-c-scroll.png` |

## 三方向比較

**A 工筆宮廷**：最貼近「摺本奏章」的核心體驗，閱讀感強，朱砂只用於御批。缺點是文字量大時密度高，動線仍以列表為主，宮廷空間感較弱。

**B 宮城平面圖**：把六個宮室變成入口，地圖感與探索感最強，符合「養成」的空間想像。缺點是資訊量被地圖佔走，需要額外的點選成本；平面圖在小螢幕上標籤容易擠。

**C 史冊卷軸**：年終回顧的儀式感最好，數據綵帶一眼可讀。缺點是更適合「年度節點」而非每日操作，若用於日常朝會會顯得笨重。

## 建議

建議以 **A 為朝堂日常主畫面，B 的平面圖作為導覽入口，C 只用於年終考評**。理由：

1. 朝堂的每日操作本質是「讀摺本、做選擇」，A 的版面最直接。
2. B 的宮城地圖適合作為切換各殿的導覽，而非取代朝堂本身，可降低首屏負擔。
3. C 的卷軸與年度節點最契合，保留其儀式感，不增加日常操作成本。

## 技術與版面約定

- 單檔、內嵌 CSS，無外部腳本；字型為內嵌 base64 之 LXGW WenKai TC 子集（標題與朱批），正文用 Noto Serif TC（Google Fonts）。
- 楷體版本註記：現行實作（web/index.html）使用 LXGW WenKai TC 比例版（取自 @fontsource/lxgw-wenkai-tc，SIL OFL），以 fontTools 子集化為 woff2 內嵌，子集涵蓋頁面與 src 文案之漢字；未涵蓋之字退回 Noto Serif TC。字重僅內嵌 400，粗體標題由瀏覽器合成。
- `:root` 定義色彩變數，並提供 `prefers-color-scheme: dark` 與 `[data-theme=dark]` 兩組深色設定。
- 375px 寬、16px 側邊距，已驗證無水平捲動。
- 影響程度以「小／中／大」表示，不顯示精確數值。
